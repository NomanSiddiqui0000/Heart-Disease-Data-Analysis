# <img src="https://images.emojiterra.com/google/noto-emoji/animated-emoji/1fac0.gif" alt="Heart Sticker" height="65"> Heart Disease Data Analysis with Power BI



This project presents an exploratory data analysis (EDA) of a heart disease dataset using **Power Query** for data preparation and **Power BI** for interactive visualizations. The objective is to understand how heart disease correlates with patient features such as sex, age, chest pain type, exercise-induced angina, and ST segment slope.

---

## 📊 Visualizations & Key Insights

### 🔹 1. Heart Disease by Sex
- **Male**: 725 cases (**~79%**)
- **Female**: 193 cases (**~21%**)
- 🔍 **Insight**: Heart disease is significantly more common in males.

### 🔹 2. Heart Disease by Chest Pain Type
- **ASY (Asymptomatic)**: 496 cases (**54%**)
- **NAP (Non-Anginal Pain)**: 203 cases (**22%**)
- **ATA (Atypical Angina)**: 173 cases (**19%**)
- **TA (Typical Angina)**: Least common
- 🔍 **Insight**: Asymptomatic chest pain is the most common type in heart disease cases.

### 🔹 3. Heart Disease by Exercise-Induced Angina
- **No Angina**: 547 cases (**60%**)
- **Yes Angina**: 371 cases (**40%**)
- 🔍 **Insight**: Majority of patients with heart disease did **not** have exercise-induced angina.

### 🔹 4. Heart Disease by Age
- 🔍 **Insight**: Heart disease incidence rises sharply with age, peaking around **50-60 years**, then decreases.

### 🔹 5. Heart Disease by Age & Chest Pain Type
- 🔍 **Insight**: Asymptomatic chest pain dominates across most age groups, especially **40 to 60**.

### 🔹 6. Heart Disease by ST Slope
- **Flat**: 460 cases  
- **Up**: 395 cases  
- **Down**: 63 cases  
- 🔍 **Insight**: Flat ST slope is the most prevalent in heart disease cases.

## 📁 Dataset Overview

The dataset includes clinical and demographic information such as:
- Age
- Sex
- Chest pain type
- Resting blood pressure
- Cholesterol
- Fasting blood sugar
- Resting ECG results
- ST depression
- ST slope
- Exercise-induced angina

## 🛠️ Tools Used

- **Power BI** — for dashboard and data visualization  
- **Power Query** — for data cleaning and transformation

## ✅ Conclusion

This Power BI dashboard provides meaningful insights into the distribution and risk factors of heart disease. It highlights patterns based on sex, age, chest pain types, ST slope, and exercise response, helping users visually understand where key risks lie.
